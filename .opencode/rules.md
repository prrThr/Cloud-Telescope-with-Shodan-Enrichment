# Regras operacionais do ibr-etl

As regras operacionais deste projeto estão centralizadas no **`AGENTS.md`**, na raiz,
que é a **fonte única de verdade**. O complemento processual (processo de trabalho,
testes e documentação) fica em `contexto/instrucoes.md`.

Este arquivo não contém regras próprias: existe apenas para redirecionar ferramentas
que o carreguem via `opencode.json` (`instructions`). **Não duplique regras aqui** —
atualize o `AGENTS.md`.
